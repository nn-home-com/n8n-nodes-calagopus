# Security Policy

## Supported versions

Security fixes are released for the latest minor version of `n8n-nodes-calagopus`.

## Reporting a vulnerability

Please do not report security issues in public GitHub issues.

Use [GitHub private vulnerability reporting](https://github.com/nn-home-com/n8n-nodes-calagopus/security/advisories/new) instead. Include the affected version, a description of the issue and steps to reproduce it. You will receive a response within a few days.

Vulnerabilities in the Calagopus Panel itself should be reported to the [Calagopus project](https://github.com/calagopus/panel/security).
